      Important: Search results are starting points, not verified recommendations or legal advice. Confirm the responsible agency, deadlines, eligibility, and current process on an official source. For immediate danger, contact local emergency services.

      Built for useful action, not noise

      01 · Find the source

      Start with public agencies and primary documents instead of unsourced claims or rumor.

      02 · Understand your options

      Learn which channels may fit: service requests, public comments, meetings, records requests, or constituent contact.

      03 · Make the project better

      Help verify local information, improve accessibility, add tests, and document what is and is not supported.

      Trust is a feature

      Honest about limits

      Suggestions are not official determinations. Coverage and source freshness must be explicit.

      Privacy first

      Do not publish personal data or unverified allegations. The current guide builds links in your browser and has no submission backend.

      Open by design

      The code and project direction are public. Fork it, challenge it, or help build a better version.

      Current status: This is an initial public concept and working static guide, not a fully verified Massachusetts-wide service. A complete municipality directory, validated jurisdiction routing, backend, and statewide coverage tests remain future work.

      Help build the civic commons

      CivicPatch is MIT-licensed. Contributors of every skill level are welcome. A careful source correction or accessibility test is just as valuable as a code change.
